Esta entrega amplía la aplicación del Mini proyecto 1 con manejo de archivos (json y csv), conjuntos (set) para detectar registros repetidos, análisis de datos con Pandas y manejo de excepciones con try/except.   • CAMPOS: diccionario con los campos que debe tener cada registro de universidades, deportistas y disciplinas; lo usa estructura_valida.

1. estructura_valida(datos)

Entradasdatos: diccionario con las llaves universidades, deportistas, disciplinas, inscripciones y resultados (los datos que se van a guardar o los que se leyeron del JSON)
SalidasTrue si la estructura es válida, False si no lo es
Procedimiento
  1. Si datos no es un diccionario retornar False
  2. Para universidades, deportistas y disciplinas: verificar que la sección sea una lista, que cada registro sea un diccionario y que cada campo de CAMPOS exista y sea texto; si algo falla retornar False
  3. Verificar que inscripciones sea una lista de filas de 2 elementos y resultados una lista de filas de 3 elementos
  4. Crear las listas de nombres de universidades, deportistas y disciplinas
  5. Verificar que cada deportista pertenezca a una universidad existente
  6. Verificar que cada inscripción use un deportista y una disciplina existentes
  7. Verificar que cada resultado use una disciplina y una universidad existentes y una medalla de MEDALLAS
  8. Si todo se cumple retornar True

lista de diccionarios

D -- Sí --> C
C -- No --> E{"¿inscripciones: filas de 2
resultados: filas de 3?"}

universidad y medalla válidas?"}
J -- No --> F
J -- Sí --> T[Retornar True] --> Z

2. repetidos(lista, campo_clave)

Entradaslista de diccionarios y el campo que identifica a cada registro (texto, por ejemplo "nombre" o "num_doc")
Salidasdos conjuntos: vistos (todos los valores encontrados, en minúsculas) y duplicados (los valores que aparecen más de una vez)
Procedimiento
  1. Crear los conjuntos vacíos vistos y duplicados
  2. Recorrer cada registro de la lista
  3. Tomar el valor del campo clave en minúsculas, para que "Javeriana Cali" y "javeriana cali" cuenten como el mismo
  4. Si el valor ya está en vistos, agregarlo a duplicados
  5. Agregar el valor a vistos (un conjunto no guarda elementos repetidos)
  6. Retornar vistos y duplicados

Diagrama de flujo

flowchart TD
A([Inicio]) --> B["vistos = conjunto vacío, duplicados = conjunto vacío"]
B --> C{"¿Quedan registros?"}
C -- No --> G["Retornar vistos, duplicados"] --> Z([Fin])
C -- Sí --> D["valor = registro[campo_clave] en minúsculas"]
D --> E{"¿valor ya está en vistos?"}
E -- Sí --> F["Agregar registro[campo_clave] a duplicados"] --> H
E -- No --> H["Agregar valor a vistos"]
H --> C

3. hay_duplicados()

Entradasninguna (usa las listas globales universidades, disciplinas y deportistas)
SalidasTrue si hay registros repetidos (y muestra una advertencia), False si no hay
Procedimiento
  1. Construir set_universidades con repetidos(universidades, "nombre")
  2. Construir set_disciplinas con repetidos(disciplinas, "nombre")
  3. Construir set_deportistas con repetidos(deportistas, "num_doc"): un deportista se identifica por su número de documento
  4. Crear el texto mensaje vacío y agregarle cada grupo que tenga repetidos
  5. Si el mensaje no está vacío, mostrar messagebox.showwarning con los datos repetidos y retornar True
  6. Si está vacío retornar False

Diagrama de flujo

flowchart TD
A([Inicio]) --> B["set_universidades, dup_universidades = repetidos(universidades, nombre)"]
B --> C["set_disciplinas, dup_disciplinas = repetidos(disciplinas, nombre)"]

D --> E["mensaje = vacío"]
E --> F{"¿Hay universidades repetidas?"}
F -- Sí --> F2["Agregar universidades repetidas al mensaje"] --> G
F -- No --> G{"¿Hay disciplinas repetidas?"}
G -- Sí --> G2["Agregar disciplinas repetidas al mensaje"] --> H
G -- No --> H{"¿Hay documentos repetidos?"}
H -- Sí --> H2["Agregar documentos repetidos al mensaje"] --> I
H -- No --> I{"¿mensaje está vacío?"}
I -- No --> J["showwarning con los datos repetidos"] --> K[Retornar True] --> Z([Fin])
I -- Sí --> L[Retornar False] --> Z

4. guardar_datos()

Entradasninguna (usa las cinco listas globales del sistema)
Salidasarchivos copa_loyola_datos.json y medallero.csv, y un mensaje de éxito o de error
Procedimiento
  1. Armar el diccionario datos con universidades, deportistas, disciplinas, inscripciones y resultados
  2. Si estructura_valida(datos) es False, mostrar error y terminar
  3. Si hay_duplicados() es True, terminar sin guardar (la advertencia ya se mostró)
  4. Dentro de try: abrir copa_loyola_datos.json en modo escritura con codificación utf-8 y escribir datos con json.dump (ensure_ascii=False para conservar tildes, indent=4 para que sea legible)
  5. Si ocurre OSError o TypeError, mostrar error y terminar
  6. Generar medallero.csv con exportar_medallero(); si falla, terminar
  7. Mostrar mensaje de éxito

C -- No --> E1["showerror: estructura no válida"] --> Z([Fin])
C -- Sí --> D{"¿hay_duplicados()?"}
D -- Sí --> Z
D -- No --> E["try: abrir copa_loyola_datos.json y escribir con json.dump"]

F -- No --> G{"¿exportar_medallero() retornó True?"}

5. cargar_datos()

Entradasarchivo copa_loyola_datos.json
Salidaslas cinco listas globales reconstruidas con el contenido del archivo, la interfaz actualizada y un mensaje con los totales (o un mensaje de error)
Procedimiento
  1. Si el archivo no existe (os.path.exists), mostrar error y terminar
  2. Dentro de try: abrir el archivo en modo lectura y leerlo con json.load
  3. Si ocurre json.JSONDecodeError, mostrar "formato inválido" y terminar
  4. Si ocurre OSError o UnicodeDecodeError, mostrar "no se pudo leer" y terminar
  5. Si estructura_valida(datos) es False, mostrar error y terminar sin tocar los datos actuales
  6. Para cada una de las cinco listas: vaciarla con clear() y llenarla con extend() con los datos del archivo (se modifica la misma lista, por eso no se necesita global)
  7. Llamar actualizar_listas() para refrescar la interfaz
  8. Mostrar mensaje con la cantidad de registros cargados
  9. Revisar duplicados con hay_duplicados(), porque un archivo editado a mano puede traer registros repetidos

Diagrama de flujo

flowchart TD
A([Inicio]) --> B{"¿Existe copa_loyola_datos.json?"}
B -- No --> E1["showerror: no existe el archivo"] --> Z([Fin])
B -- Sí --> C["try: abrir el archivo y leer con json.load"]
C --> D{"¿Ocurrió JSONDecodeError?"}
D -- Sí --> E2["showerror: formato inválido"] --> Z
D -- No --> D2{"¿Ocurrió OSError o UnicodeDecodeError?"}
D2 -- Sí --> E3["showerror: no se pudo leer"] --> Z
D2 -- No --> F{"¿estructura_valida(datos)?"}
F -- No --> E4["showerror: estructura no esperada"] --> Z
F -- Sí --> G{"¿Quedan listas por reemplazar?"}
G -- Sí --> H["lista.clear() y lista.extend(datos[seccion])"] --> G
G -- No --> I["actualizar_listas()"]
I --> J["showinfo con los totales cargados"]
J --> K["hay_duplicados()"] --> Z

6. exportar_medallero()

Entradasninguna (usa calcular_medallero, que lee las listas universidades y resultados)
Salidasarchivo medallero.csv; retorna True si se creó y False si ocurrió un error
Procedimiento
  1. Calcular el medallero {universidad: [oros, platas, bronces]} con calcular_medallero()
  2. Dentro de try: abrir medallero.csv en modo escritura con newline="" (evita filas en blanco en Windows) y codificación utf-8-sig (para que Excel muestre las tildes)
  3. Crear un csv.writer y escribir el encabezado Universidad, Oro, Plata, Bronce
  4. Escribir una fila por universidad: su nombre seguido de sus tres cantidades
  5. Si ocurre OSError (por ejemplo, el archivo está abierto en Excel), mostrar error y retornar False
  6. Retornar True

8. generar_reporte()

Entradasninguna (usa la lista global resultados y las constantes MEDALLAS y PUNTOS)
Salidasventana Toplevel con la tabla de universidades, medallas y puntos y la universidad ganadora; archivo reporte_copa_loyola.csv; mensaje de éxito o de error
Procedimiento
  1. Si no hay resultados, mostrar advertencia y terminar
  2. Crear el DataFrame df con los resultados y ordenar sus columnas como Universidad, Disciplina, Medalla
  3. Contar las medallas por universidad y por tipo con groupby(["Universidad", "Medalla"]).size() y convertir los tipos de medalla en columnas con unstack(fill_value=0)
  4. Con reindex dejar las columnas en el orden Oro, Plata, Bronce y crear con 0 la que no exista
  5. Calcular la columna Puntos = Oro*3 + Plata*2 + Bronce*1
  6. Ordenar de mayor a menor por Puntos, Oro, Plata y Bronce (criterio de desempate)
  7. Tomar la primera fila como la mejor (iloc[0]) y guardar como ganadoras todas las universidades con la misma fila (loc)
  8. Armar las líneas de la tabla y agregar "Universidad ganadora" o "Empate entre"
  9. Crear una ventana Toplevel con un título y un Listbox, y mostrar las líneas
  10. Dentro de try: exportar df a reporte_copa_loyola.csv con to_csv (sin la columna de índice)
  11. Si ocurre OSError mostrar error; si no, mostrar mensaje de éxito

Diagrama de flujo

flowchart TD

B -- Sí --> W["showwarning: no hay resultados"] --> Z([Fin])
B -- No --> C["df = DataFrame con columnas Universidad, Disciplina, Medalla"]
C --> D["conteo = agrupar por Universidad y Medalla,
contar y pasar medallas a columnas"]
D --> E["Ordenar columnas Oro, Plata, Bronce

F --> G["Ordenar por Puntos, Oro, Plata, Bronce de mayor a menor"]
G --> H["mejor = primera fila
ganadoras = universidades con la misma fila"]
H --> I["Armar las líneas de la tabla"]
I --> J{"¿Hay una sola ganadora?"}
J -- Sí --> K["Agregar Universidad ganadora"] --> M
J -- No --> L["Agregar Empate entre las ganadoras"] --> M

10. Validaciones y manejo de errores

Requisito del enunciadoCómo se cumple
1. Verificar que el JSON exista antes de cargarloos.path.exists en cargar_datos
2. Manejar JSON con formato inválido o que no se pueda leerexcept json.JSONDecodeError y except (OSError, UnicodeDecodeError) en cargar_datos
3. Verificar que la información tenga una estructura válidaestructura_valida, antes de guardar y antes de reemplazar los datos al cargar
4. Detectar duplicados con conjuntos y advertir con showwarningrepetidos y hay_duplicados, al guardar y al cargar
5. Informar errores al generar o exportar CSVexcept OSError en exportar_medallero y en generar_reporte
6. Informar cuando guardar, cargar y generar reportes finalicen bienmessagebox.showinfo al final de guardar_datos, cargar_datos, boton_medallero y generar_reporte

Se conservan todas las validaciones del Mini proyecto 1 (campos obligatorios, registros repetidos, documento numérico, existencia de universidades y disciplinas, y no eliminar registros con datos asociados).

  • copa_loyola_datos.json: todos los datos del sistema.
  • medallero.csv: medallas por universidad.
